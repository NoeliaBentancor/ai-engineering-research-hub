# Design System

## Color Palette
- Primary: #2c3e50 (Dark Blue)
- Secondary: #3498db (Bright Blue)
- Background: #f4f4f4 (Light Gray)
- Text: #2c3e50 (Dark Blue) and #6c757d (Gray)

## Typography
- Font Family: System fonts (Segoe UI, Roboto, etc.)
- Headings: Responsive hierarchy with h1-h6
- Body text: Readable and accessible

## Components 
- Header with navigation (sticky top)
- Section-based layout
- Research cards with basic styling
- Footer with copyright information

## Layout
- Responsive grid system
- Mobile-first approach
- Max-width container for content
- Basic spacing and margins

## Interactions
- Hover effects on links
- Simple transitions
- Loading states

## Accessibility Considerations
- Semantic HTML structure
- Color contrast ratios
- Screen reader compatibility

## Device Support
- Mobile responsive (768px breakpoint)
- Tablet and desktop layouts
